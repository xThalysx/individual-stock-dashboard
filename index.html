IBKR Live Market Data

Connect to your authenticated local Trader Workstation or IB Gateway session for live last price, bid, ask, daily volume, shortable shares, and borrow fee. Existing dashboard providers remain available as the fallback.

Enable API socket access in TWS/Gateway and keep it running. When the preferred mode is on, the dashboard uses IBKR ticks first and automatically falls back to its current providers if Gateway or a subscription is unavailable.

IBKR API Setup GuideTurn off “Prefer IBKR live market data” at any time to use the dashboard’s prior live-data sources only. Historical charts, financials, news, and reported short interest continue using their existing sources.

Remove ticker?

Its research notes will be saved and restored if you add the ticker again.

Reconnect Brokerage

SnapTrade needs you to sign in to the brokerage again before it can retrieve current holdings. Credentials are entered only in SnapTrade’s secure connection window.

Request Manual Sync?

This asks SnapTrade to queue a fresh holdings sync for every active brokerage connection. It can take several minutes. SnapTrade may charge for this request or reject it if your plan does not include manual refresh.
